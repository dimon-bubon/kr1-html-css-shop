Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы.

## Текущий статус

Выполнен БЭМ-рефакторинг CSS-стилей. Проект состоит из трёх страниц (главная, каталог, контакты), единого CSS-файла и JavaScript для модального окна с формой заявки.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`, разбитый по БЭМ-блокам.

## Использование Flexbox и Grid

- Flexbox: основное меню (`site-nav`), внутренняя структура карточек (`product-card`), блок преимуществ (`advantages`), кнопки формы (`order-form__actions`);
- CSS Grid: сетка карточек (`products-grid`) и страница каталога с фильтрами (`catalog-layout`).

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `advantages` — преимущества магазина;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `catalog-products` — список товаров каталога;
- `contact-list` — список контактов;
- `info-box` — информационная врезка;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `success-message` — сообщение об успешной отправке;
- `button` — кнопка;
- `site-footer` — подвал сайта.

### Примеры элементов (`block__element`)

- `site-header__inner`, `site-header__logo`;
- `site-nav__list`, `site-nav__item`, `site-nav__link`;
- `product-card__title`, `product-card__description`, `product-card__price`, `product-card__button`;
- `order-form__field`, `order-form__label`, `order-form__input`, `order-form__actions`;
- `breadcrumbs__link`, `breadcrumbs__current`.

### Примеры модификаторов (`block--modifier`)

- `site-nav__link--active` — ссылка текущей страницы;
- `product-card--featured`, `product-card--discount` — варианты карточки товара;
- `button--primary`, `button--secondary`, `button--disabled` — варианты кнопки;
- `order-form__field--checkbox` — поле формы с чекбоксом.

### Правила именования

- блок: `product-card`;
- элемент: `product-card__title`;
- модификатор: `product-card--discount` (всегда вместе с основным классом блока);
- классы описывают назначение элемента, а не внешний вид;
- стили задаются по классам, без вложенных селекторов и без `id`;
- `id` оставлены только для якорных ссылок и JavaScript (`order-dialog`, `order-form`, `close-order-dialog`, `selected-product`, `success-message`, `popular`, `advantages`, `contacts` и др.).
